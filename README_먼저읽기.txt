별덕이 — 학교 크롬북 웹 전용판

이 버전은 Chrome 확장 프로그램을 전혀 사용하지 않습니다.
chrome://extensions 접근 권한도 필요 없습니다.

[가장 추천하는 사용법]
1. 이 폴더 전체를 GitHub Pages에 올립니다.
2. 생성된 https://...github.io/... 주소를 학교 크롬북에서 엽니다.
3. '작업용 떠다니는 별덕이' 버튼을 누릅니다.
4. Chrome이 Document Picture-in-Picture를 허용하면 작은 항상-위 창이 열립니다.
5. 다른 탭에서 과제를 해도 별덕이 창을 옆에 띄워둘 수 있습니다.

[학교 정책이 PiP를 막는 경우]
- 자동으로 일반 팝업 창을 시도합니다.
- 팝업도 차단된 경우에는 메인 웹페이지 안에서 별덕이가 계속 움직입니다.

[중요한 제한]
일반 웹사이트는 보안상 다른 웹사이트나 Chromebook 전체 데스크톱 위를 투명하게 덮고
캐릭터를 자유롭게 돌아다니게 할 권한이 없습니다.
그 기능은 확장 프로그램이나 운영체제 수준 앱 권한이 필요합니다.
이 버전은 학교 관리 정책을 우회하지 않고 웹에서 허용되는 범위만 사용합니다.

[PWA 설치]
Chrome 메뉴에 '앱 설치' 또는 '설치'가 보인다면 설치할 수 있습니다.
학교 관리자가 PWA 설치를 막았다면 설치하지 않아도 웹사이트 자체는 그대로 사용할 수 있습니다.
